# hackaway-project-01
The project designed and implemented for The Royal Hackaway 2025

## For developers:
- Make sure you have the latest version of Python installed: https://www.python.org/downloads/
- `requirements.txt` don't have any dependencies yet (W.I.P)
- Use the official GitHub page of this repository (project) to track the list of issues as they are tasks required to complete to achieve primary project goals.
- The primary idea of the project is not finalised yet, so the current repository might face several major changes.
- Have fun and don't forget about regular breaks!

### To get started:
1. Find a folder where you store your projects (for convenience)
2. Use these commands to clone a git repository:
```
git clone https://github.com/elh0mbr3/hackaway-project-01.git
git pull
```
3. For contributing:
- `git add [filename].[type]` to add a specific file or `git add .` to add all files modified/added (be careful with the last one).
- `git commit -m "[your commit message]"`
(!) Recommended to use imperative verbs. For instance, `Add README.md for the purpose of documentation`.
- `git push` to push all of the changes to the main branch (both on local and remote Git repositories).
